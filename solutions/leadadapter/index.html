From research to a deliberate CRM commit

  1. Request focused people research and wait for its completed job result.
  2. Find the ingested prospects by exact full URN or public ID; never infer identity from a display name.
  3. Review and explicitly approve the selected prospect IDs before native LeadAdapter CRM promotion.
  4. Optionally name an external connected provider and approve that separate CRM sync.

Pending ingestion stays resumable. Private checkpoints retain stable request keys; uncertain writes hold for reconciliation rather than replaying.

SDK0.2: compose the workflow

The Node and Python SDKs offer ergonomic resources on the existing REST API, retain their low-level request methods, and include a no-network plan plus source-shaped fixture workflow.

node lib/cli.mjs workflows research-to-crm --fixture
python3 -m leadadapter workflows research-to-crm --fixture

Run the Node command from the matching Node SDK release and the Python command from its installed wheel/source package. Fixture mode stops for review before writes.

MCP bridge0.3: discover the real remote tools

The current bridge initializes LeadAdapter’s remote MCP endpoint at https://leadadapter.com/mcp, discovers its actual tools, and forwards calls under your scoped workspace key. Tool names and availability come from the remote service.

export LEADADAPTER_API_KEY="YOUR_WORKSPACE_API_KEY"
node lib/cli.mjs

Run from the matching linkedin-mcp release. node example.mjs --live lists remote tools only; discovery does not prove a LinkedIn operation ran.

Find the client, install the skills

linkedin-api · linkedin-typescript-sdk · linkedin-python-sdk · linkedin-mcp

Matching SDK releases bundle task skills for Codex, Claude and Grok. Use the supported installer with explicit project scope:

node lib/cli.mjs agents install --client codex --scope project --project /path/to/project
python3 -m leadadapter agents install --client claude --scope project --project /path/to/project

Project-local guidance belongs under .agents/skills or .claude/skills as supported by the chosen client. Installing skills grants no credentials or write approval. Check each repository’s current release assets and README for the agentkit included in that version.

Access and exact evidence boundaries

Use only your LeadAdapter workspace key. Fresh LinkedIn research needs a connected supported execution mode, required consent and applicable plan allowances. Reads use their documented read scope; promotion and external sync need write access and explicit approval.

The public SDK and bridge code connect to LeadAdapter’s private hosted service. They do not include its backend. SDK fixture tests establish client behavior. MCP initialization/tools-list tests establish protocol discovery. Neither establishes live provider execution, native promotion or external delivery.

PipMCP gateway clients use their own PIPMCP_API_KEY and hosted provider connections. LeadAdapter continues to use its separate workspace key. Historical local PipMCP proof does not establish current hosted results.
