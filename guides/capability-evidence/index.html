How capability evidence works

Documented, Tested and Live describe recorded proof for local or managed operations, not marketing tiers.

Documented

The provider source or implementation describes the operation and its prerequisites. No successful execution is established by this level.

Tested

Recorded tests cover a named capability. Local tests may use fixtures or mock transports. They verify contract handling; they do not establish authentication or provider behavior on a real account.

Live

A named operation has recorded live execution evidence. The local and managed modes are evaluated separately. The directory requires an operation-level Live record with an evidence reference before showing this level.

What never proves a Live operation

A repository existing, an API schema importing, a client configuration validating, an MCP initialize response or tools/list succeeding does not prove provider operation execution.
