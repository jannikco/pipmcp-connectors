Setup doctors and hosted connector clients

Setup doctor

A setup page describes prerequisites and can provide an offline plan or authenticated diagnostics. It does not promise a configured or executable provider connector.

Hosted connector client

The public package transports requests to PipMCP using PIPMCP_API_KEY. Actual tool names, schemas, connections, permissions and execution come from the hosted workspace; private provider profiles are not shipped.

Historical local releases

Historical MIT code and operation evidence apply to their pinned versions. They are not proof that a current hosted operation ran successfully.
