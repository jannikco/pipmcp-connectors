Setup guides and connector implementations

Understand which directory artifacts describe prerequisites and which implement named API operations.

Setup guide

A setup page records a provider, its documentation, authentication requirements and connection path. It can be useful before executable operations are available. It does not imply that an API import, authentication flow or provider operation has been tested.

Connector implementation

A connector implements named operations with explicit HTTP methods, paths and input mappings. Its local and managed evidence remain separate. A runnable local connector can exist before a managed connection has been exercised.

Published repository

Repository links appear only when a publication receipt or remote audit records an initialized public repository. The repository README states the currently released artifact. A directory page does not require a separate repository.
