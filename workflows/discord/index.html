Discord WORKFLOW

Community channel inventory

Confirm bot identity and list a guild’s channels before drafting a community update.

Documented Workflow definition · 2 real tool steps
Open PipMCP setup ↗

Prerequisites and sequence

Create an API key in your authorized Discord account. Requests send the key in the configured authentication header.

  1. get_current_user — Read the bot’s current Discord user.
  2. list_guild_channels — List channels in a guild where your bot has access.

The definition references existing connector operations in the order above. Individual-step evidence does not establish that the composed workflow has been executed successfully. Inspect each result before continuing, and explicitly authorize any write step.

Run the local connector

Open source, with your own provider credentials. Provider API access and any provider charges remain yours. No PipMCP account is required for local execution.

Node.js22+ · terminal
git clone https://github.com/jannikco/discord-mcp.git
cd discord-mcp
npm ci --ignore-scripts
npm test
npm start

The default command shows the available operations offline. Provide DISCORD_BOT_TOKEN through environment variables or the supported local OS-vault resolver.

For a stdio MCP client, launch npm run server in the checkout. Open the released connector for full client configuration →
