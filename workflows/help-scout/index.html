Prerequisites and sequence

Follow Help Scout's official authentication guide before connecting credentials. The required authorization flow must be confirmed for your account.

  1. helpscout_list_conversations — Read one page of active conversations, optionally filtered by mailbox.
  2. helpscout_get_conversation — Read one conversation by ID. Merged-conversation redirects are rejected rather than followed.

The definition references existing connector operations in the order above. Individual-step evidence does not establish that the composed workflow has been executed successfully. Inspect each result before continuing, and explicitly authorize any write step.

Run the local connector

Open source, with your own provider credentials. Provider API access and any provider charges remain yours. No PipMCP account is required for local execution.

Node.js22+ · terminal
git clone https://github.com/jannikco/help-scout-mcp.git
cd help-scout-mcp
npm ci --ignore-scripts
npm test
npm start

The default command shows the available operations offline. Provide HELP_SCOUT_ACCESS_TOKEN through environment variables or the supported local OS-vault resolver.

For a stdio MCP client, launch npm run server in the checkout. Open the released connector for full client configuration →
