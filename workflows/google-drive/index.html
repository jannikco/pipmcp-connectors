Google Drive WORKFLOW

Shared document discovery

Search available file metadata and inspect a chosen document before requesting its contents.

Documented Workflow definition · 2 real tool steps
Open PipMCP setup ↗

Prerequisites and sequence

Configure the Google Drive OAuth application described in its authentication guide, then authorize your own account. App scopes and callback registration must match your intended operations.

  1. list_files — List file metadata accessible to the authorized user.
  2. get_file_metadata — Read a chosen file’s metadata; does not download file contents.

The definition references existing connector operations in the order above. Individual-step evidence does not establish that the composed workflow has been executed successfully. Inspect each result before continuing, and explicitly authorize any write step.

Run the local connector

Open source, with your own provider credentials. Provider API access and any provider charges remain yours. No PipMCP account is required for local execution.

Node.js22+ · terminal
git clone https://github.com/jannikco/google-drive-mcp.git
cd google-drive-mcp
npm ci --ignore-scripts
npm test
npm start

The default command shows the available operations offline. Provide GOOGLE_DRIVE_ACCESS_TOKEN through environment variables or the supported local OS-vault resolver.

For a stdio MCP client, launch npm run server in the checkout. Open the released connector for full client configuration →
