Trello WORKFLOW

Board portfolio briefing

Identify the current member and read open boards for a portfolio status summary.

Documented Workflow definition · 2 real tool steps
Open PipMCP setup ↗

Prerequisites and sequence

Follow Trello's authentication guide to prepare the named credential headers. Header names are listed below; provide their values through your chosen local or managed credential flow.

  1. get_current_member — Read the member associated with your Trello token.
  2. list_member_boards — Read boards visible to the current member.

The definition references existing connector operations in the order above. Individual-step evidence does not establish that the composed workflow has been executed successfully. Inspect each result before continuing, and explicitly authorize any write step.

Run the local connector

Open source, with your own provider credentials. Provider API access and any provider charges remain yours. No PipMCP account is required for local execution.

Node.js22+ · terminal
git clone https://github.com/jannikco/trello-mcp.git
cd trello-mcp
npm ci --ignore-scripts
npm test
npm start

The default command shows the available operations offline. Provide TRELLO_TOKEN through environment variables or the supported local OS-vault resolver.

For a stdio MCP client, launch npm run server in the checkout. Open the released connector for full client configuration →
