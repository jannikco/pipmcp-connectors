Kit (ConvertKit) authorized workflow

Find subscribers and explicitly create an inactive subscriber record without activating a subscription.

Documented Workflow definition · 2 real tool steps

Prerequisites and sequence

Create an API key in your authorized Kit (ConvertKit) account. Requests send the key in the configured authentication header.

  1. kit_list_subscribers — Read a page of subscribers with optional email filtering.
  2. kit_create_inactive_subscriber — Create an inactive subscriber; this does not subscribe them to email marketing.

The definition references existing connector operations in the order above. Individual-step evidence does not establish that the composed workflow has been executed successfully. Inspect each result before continuing, and explicitly authorize any write step.

Run the local connector

Open source, with your own provider credentials. Provider API access and any provider charges remain yours. No PipMCP account is required for local execution.

Node.js22+ · terminal
git clone https://github.com/jannikco/kit-mcp.git
cd kit-mcp
npm ci --ignore-scripts
npm test
npm start

The default command shows the available operations offline. Provide KIT_API_KEY through environment variables or the supported local OS-vault resolver.

For a stdio MCP client, launch npm run server in the checkout. Open the released connector for full client configuration →
