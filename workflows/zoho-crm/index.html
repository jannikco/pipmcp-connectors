Zoho CRM authorized workflow

Review lead records and explicitly create an authorized new lead in a US-region CRM.

Prerequisites and sequence

Follow Zoho CRM's official authentication guide before connecting credentials. The required authorization flow must be confirmed for your account.

  1. zoho_list_leads — Read a page of leads with an explicit field selection.
  2. zoho_create_lead — Create one lead; CRM-specific mandatory fields and validation still apply.

The definition references existing connector operations in the order above. Individual-step evidence does not establish that the composed workflow has been executed successfully. Inspect each result before continuing, and explicitly authorize any write step.

Run the local connector

Open source, with your own provider credentials. Provider API access and any provider charges remain yours. No PipMCP account is required for local execution.

Node.js22+ · terminal
git clone https://github.com/jannikco/zoho-crm-mcp.git
cd zoho-crm-mcp
npm ci --ignore-scripts
npm test
npm start

The default command shows the available operations offline. Provide ZOHO_CRM_ACCESS_TOKEN through environment variables or the supported local OS-vault resolver.

For a stdio MCP client, launch npm run server in the checkout. Open the released connector for full client configuration →
