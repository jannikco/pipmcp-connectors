Mailchimp WORKFLOW

Mailchimp authorized workflow

Inspect audiences and their members before explicitly requesting double opt-in for a consenting subscriber.

Documented Workflow definition · 3 real tool steps
Import with PipMCP ↗

Prerequisites and sequence

Use the Mailchimp username and password required for HTTP Basic authentication.

  1. mailchimp_list_audiences — List one page of audiences.
  2. mailchimp_list_members — List members in one authorized audience.
  3. mailchimp_add_pending_member — Add a consenting subscriber with pending status, triggering Mailchimp double opt-in confirmation.

The definition references existing connector operations in the order above. Individual-step evidence does not establish that the composed workflow has been executed successfully. Inspect each result before continuing, and explicitly authorize any write step.

Run the local connector

Open source, with your own provider credentials. Provider API access and any provider charges remain yours. No PipMCP account is required for local execution.

Node.js22+ · terminal
git clone https://github.com/jannikco/mailchimp-mcp.git
cd mailchimp-mcp
npm ci --ignore-scripts
npm test
npm start

The default command shows the available operations offline. Provide MAILCHIMP_USERNAME, MAILCHIMP_API_KEY through environment variables or the supported local OS-vault resolver.

For a stdio MCP client, launch npm run server in the checkout. Open the released connector for full client configuration →
