Google Contacts WORKFLOW

Inspect personal contacts and create a reviewed contact

Inspect personal contacts and create a reviewed contact. Read provider data first, then explicitly approve the selected change with operator write opt-in and a unique per-call approval key.

Documented Workflow definition · 3 real tool steps
Open PipMCP setup ↗

Prerequisites and sequence

Follow Google Contacts's official authentication guide before connecting credentials. The required authorization flow must be confirmed for your account.

  1. list_connections — List connections.
  2. get_contact — Get contact.
  3. create_contact — Create contact.

The definition references existing connector operations in the order above. Individual-step evidence does not establish that the composed workflow has been executed successfully. Inspect each result before continuing, and explicitly authorize any write step.

Run the local connector

Open source, with your own provider credentials. Provider API access and any provider charges remain yours. No PipMCP account is required for local execution.

Node.js22+ · terminal
git clone https://github.com/jannikco/google-contacts-mcp.git
cd google-contacts-mcp
npm ci --ignore-scripts
npm test
npm start

The default command shows the available operations offline. Provide GOOGLE_CONTACTS_ACCESS_TOKEN through environment variables or the supported local OS-vault resolver.

For a stdio MCP client, launch npm run server in the checkout. Open the released connector for full client configuration →
