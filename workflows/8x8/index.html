8x8 WORKFLOW

8x8-workflow

Inspect messaging account balance/status and explicitly approve one SMS in the correct account region.

Documented Workflow definition · 3 real tool steps
Open PipMCP setup ↗

Prerequisites and sequence

Obtain an authorized 8x8 bearer token. Requests send it in the Authorization header.

  1. eightx8_get_balance — eightx8 get balance
  2. eightx8_get_sms — eightx8 get sms
  3. eightx8_send_sms — Send one SMS to an explicitly authorized recipient. Default endpoint is Asia-Pacific; select the documented host for your account region.

The definition references existing connector operations in the order above. Individual-step evidence does not establish that the composed workflow has been executed successfully. Inspect each result before continuing, and explicitly authorize any write step.

Run the local connector

Open source, with your own provider credentials. Provider API access and any provider charges remain yours. No PipMCP account is required for local execution.

Node.js22+ · terminal
git clone https://github.com/jannikco/8x8-mcp.git
cd 8x8-mcp
npm ci --ignore-scripts
npm test
npm start

The default command shows the available operations offline. Provide EIGHTX8_API_KEY through environment variables or the supported local OS-vault resolver.

For a stdio MCP client, launch npm run server in the checkout. Open the released connector for full client configuration →
