LinkedIn WORKFLOW

LinkedIn account and stored-lead inspection

Inspect your connected profile state, then retrieve your workspace’s stored leads before planning further governed LinkedIn actions.

Documented Workflow definition · 2 real tool steps
Open PipMCP setup ↗

Prerequisites and sequence

Configure the LinkedIn OAuth application described in its authentication guide, then authorize your own account. App scopes and callback registration must match your intended operations.

  1. get_extension_status_get — Extension status
  2. list_leads_get — List Leads

The definition references existing connector operations in the order above. Individual-step evidence does not establish that the composed workflow has been executed successfully. Inspect each result before continuing, and explicitly authorize any write step.

Run the local connector

Open source, with your own provider credentials. Provider API access and any provider charges remain yours. No PipMCP account is required for local execution.

Node.js22+ · terminal
git clone https://github.com/jannikco/linkedin-mcp.git
cd linkedin-mcp
npm ci --ignore-scripts
npm test
npm start

The default command shows the available operations offline. Provide LEADADAPTER_API_KEY through environment variables or the supported local OS-vault resolver.

For a stdio MCP client, launch npm run server in the checkout. Open the released connector for full client configuration →
