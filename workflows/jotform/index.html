Jotform WORKFLOW

Jotform authorized workflow

Find an authorized form and read a bounded page of its submitted responses.

Documented Workflow definition · 2 real tool steps
Import with PipMCP ↗

Prerequisites and sequence

Create an API key in your authorized Jotform account. Requests send the key in the configured authentication header.

  1. jotform_list_forms — List account forms using the APIKEY header.
  2. jotform_list_submissions — Read one page of submissions for a chosen form; results may contain personal information.

The definition references existing connector operations in the order above. Individual-step evidence does not establish that the composed workflow has been executed successfully. Inspect each result before continuing, and explicitly authorize any write step.

Run the local connector

Open source, with your own provider credentials. Provider API access and any provider charges remain yours. No PipMCP account is required for local execution.

Node.js22+ · terminal
git clone https://github.com/jannikco/jotform-mcp.git
cd jotform-mcp
npm ci --ignore-scripts
npm test
npm start

The default command shows the available operations offline. Provide JOTFORM_API_KEY through environment variables or the supported local OS-vault resolver.

For a stdio MCP client, launch npm run server in the checkout. Open the released connector for full client configuration →
