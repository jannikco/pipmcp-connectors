Run the local connector

Open source, with your own provider credentials. Provider API access and any provider charges remain yours. No PipMCP account is required for local execution.

Node.js22+ · terminal
git clone https://github.com/jannikco/apify-mcp.git
cd apify-mcp
npm ci --ignore-scripts
npm test
npm start

The default command shows the available operations offline. Provide APIFY_TOKEN through environment variables or the supported local OS-vault resolver.

For a stdio MCP client, launch npm run server in the checkout. Open the released connector for full client configuration →

Credentials and account access

Obtain an authorized Apify bearer token. Requests send it in the Authorization header.

Local execution

Set APIFY_TOKEN in your environment, or use the connector's supported OS-vault credential resolver. Credentials remain in your chosen local credential flow; the local server does not upload them to PipMCP.

Optional managed connection

Connect credentials separately in the hosted service. The hosted flow applies its own permissions and account controls.
