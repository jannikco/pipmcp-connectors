One PipMCP key, hosted provider access

Create an account key with connectors:read for discovery and connectors:call for calls. Set PIPMCP_API_KEY in the client environment. Connect the authorized provider account in PipMCP.

When multiple accounts are available, choose explicit PIPMCP_INTEGRATION_ID and PIPMCP_CONNECTION_ID from the hosted inventory. A missing app, missing connection and insufficient scope are different account conditions.

Discover the tools your account can use

This package reads the actual published tool names and schemas from PipMCP. It does not bundle provider HTTP routes, credential mappings or execution plans.

The connector executes through the private hosted gateway. The selected account and live inventory define which operations are callable.

node lib/cli.mjs doctor --connector microsoft-outlook

Ordinary MCP tool calls go through hosted permissions and confirmation policy. A pending confirmation must be reviewed in PipMCP; the bridge never approves it. A subsequent explicit call resumes that same confirmation with its original key. Uncertain writes remain held.
