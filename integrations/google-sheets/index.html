Run the local connector

Open source, with your own provider credentials. Provider API access and any provider charges remain yours. No PipMCP account is required for local execution.

Node.js22+ · terminal
git clone https://github.com/jannikco/google-sheets-mcp.git
cd google-sheets-mcp
npm ci --ignore-scripts
npm test
npm start

The default command shows the available operations offline. Provide GOOGLE_SHEETS_ACCESS_TOKEN through environment variables or the supported local OS-vault resolver.

For a stdio MCP client, launch npm run server in the checkout. Open the released connector for full client configuration →

Credentials and account access

Follow Google Sheets's official authentication guide before connecting credentials. The required authorization flow must be confirmed for your account.

Local execution

Set GOOGLE_SHEETS_ACCESS_TOKEN in your environment, or use the connector's supported OS-vault credential resolver. Credentials remain in your chosen local credential flow; the local server does not upload them to PipMCP.

Optional managed connection

Connect credentials separately in the hosted service. The hosted flow applies its own permissions and account controls.

Provider credential fields: GOOGLE_SHEETS_ACCESS_TOKEN.
