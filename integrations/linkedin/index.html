Run the local connector

Open source, with your own provider credentials. A LeadAdapter account and scoped API access are required. No PipMCP account is required for local execution.

Node.js22+ · terminal
git clone https://github.com/jannikco/linkedin-mcp.git
cd linkedin-mcp
npm ci --ignore-scripts
npm test
npm start

The default command shows the available operations offline. Provide LEADADAPTER_API_KEY through environment variables or the supported local OS-vault resolver.

For a stdio MCP client, launch npm run server in the checkout. Open the released connector for full client configuration →

Credentials and account access

Create a scoped LeadAdapter API key in your own workspace and keep it in the local client environment. API authentication and the connected LinkedIn profile are separate prerequisites; execution still depends on the enabled adapter, account access and owner consent.

Local execution

Set LEADADAPTER_API_KEY in your environment, or use the connector's supported OS-vault credential resolver. Credentials remain in your chosen local credential flow; the local server does not upload them to PipMCP.

Optional managed connection

Connect credentials separately in the hosted service. The hosted flow applies its own permissions and account controls.

Provider credential fields: LEADADAPTER_API_KEY.
