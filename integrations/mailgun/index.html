Run the local connector

Open source, with your own provider credentials. Provider API access and any provider charges remain yours. No PipMCP account is required for local execution.

Node.js22+ · terminal
git clone https://github.com/jannikco/mailgun-mcp.git
cd mailgun-mcp
npm ci --ignore-scripts
npm test
npm start

The default command shows the available operations offline. Provide MAILGUN_BASIC_USERNAME, MAILGUN_API_KEY through environment variables or the supported local OS-vault resolver.

For a stdio MCP client, launch npm run server in the checkout. Open the released connector for full client configuration →

Credentials and account access

Use the Mailgun username and password required for HTTP Basic authentication.

Local execution

Set MAILGUN_BASIC_USERNAME, MAILGUN_API_KEY in your environment, or use the connector's supported OS-vault credential resolver. Credentials remain in your chosen local credential flow; the local server does not upload them to PipMCP.

Optional managed connection

Connect credentials separately in the hosted service. The hosted flow applies its own permissions and account controls.

Provider credential fields: MAILGUN_BASIC_USERNAME, MAILGUN_API_KEY.
